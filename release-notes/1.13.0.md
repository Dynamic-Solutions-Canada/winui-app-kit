- The shared Store workflow now sets "What's new" for every listing locale, not just English. Each locale reads its own release notes (`release-notes/<version>.<catalog>.md`; en-CA and fr-CA use the en-US and fr-FR notes) and falls back to the English notes where there is no translation.
- An app with `"listing": {"catalog_dir": null}` gets its English notes in every locale. Any notes file over 1,500 characters, or empty, stops the run before anything is built.

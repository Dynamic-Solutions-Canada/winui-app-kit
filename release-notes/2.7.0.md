- Nothing changes for an app until it adds a hero; apps without one need no edit.
- **Generated first Store screenshot (D-123):** `scripts/devkit hero` draws the listing's first screenshot in every listing locale with devkit's `devkit-store-hero`, and `scripts/devkit hero --check` keeps it current in `validate`. Add a `hero` entry first in `store-assets/manifest.json` and a `heroHeadline` (and `heroSubline`) to each locale in `listings.json`. See "The first screenshot: a generated hero" in the README.
- **Listing check:** `check:listing` accepts `heroHeadline` and `heroSubline`. Each must be in every full record or none.
- **Screenshot check:** `check:screenshots` leaves the hero to devkit. It checks that the hero is first, that its path contains `{locale}`, and that every locale with its own record has its image at the output size. A hero may use a 200% capture.
- **Fonts and platform:** the first `hero` run downloads devkit's pinned fonts (about 27 MB) into the user's cache. Run `hero --check` on Linux (WSL, or the Store workflow's gate), where devkit has shown identical pixels.
- The kit's devkit tools move to devkit v0.27.0; `icons` and `precommit` behave as before.

- New "Check for updates" for your About page: `UpdateService` opens the Microsoft Store's updates page when your app is packaged. When it isn't, it checks your GitHub Releases (only your lane's tags in a monorepo) and links to the newer release. It never checks in the background. Pass your repository's current owner and name.
- New shared XAML: import `Xaml/WinUIAppKit.Xaml.projitems` to get the family's page and card styles under the keys you already use, the settings window shell with the standard footer ("Our other apps", then "About"), and the About page with the standard cards. Your app compiles them itself, so packaging is unchanged. The README's "Shared XAML" section shows the import and the code.
- Shared labels such as "Start with Windows", "Use system setting" and the About page text now come translated from the kit as `kit.*` keys, so they read the same in every app. When you switch, remove your own copies of these labels and don't define `kit.` keys. Some of the new translations are machine translations that nobody has reviewed yet.
- Nothing changes for your app until you adopt these: existing APIs and behaviour are as in 1.0.0.

- **On-screen displays:** `OsdController` turns a window into a popup like Windows' volume display: bottom centre, never activated, click-through, held then faded, and parked off-screen so it reappears instantly. It uses acrylic and rounded corners on Windows 11, and a solid background in the window's theme with square corners on Windows 10. It registers its window with `HostWindow.CloseOnExit` itself.
- The kit's `NativeMethods` now declares `HWND_TOPMOST`, `LWA_ALPHA` and `SetLayeredWindowAttributes`. An app that declares its own and imports both classes with `using static` gets ambiguous-name errors: delete the app's copies.

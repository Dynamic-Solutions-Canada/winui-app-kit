- New one packaging script: point `package_script` in your windows-build.json at `external/winui-app-kit/build/build-msix.ps1` and delete your own. Everything that differs between apps is a setting in windows-build.json, listed in the README's "Packaging" section. Signing certificates come only from the build tooling; the script stores and generates none.
- New one build command wrapper: call `external/winui-app-kit/scripts/windows-build` from your npm scripts and delete your own copy. It builds the folder npm runs it in. Run any preparation step in its own npm script first.
- New `check:l10n` for your `validate`: `python3 external/winui-app-kit/scripts/check-localization.py`, configured by a `localization` block in windows-build.json. Delete your own catalog check. It also fails if your catalogs define `kit.` keys.
- `build/languages.json` is now the family's one language list; the packaging script and the check both read it.
- `ConfirmDialog.ConfirmAsync` no longer needs a cancel label: it uses the kit's translated "Cancel" unless you pass one.
- Nothing changes for your app until you adopt these.

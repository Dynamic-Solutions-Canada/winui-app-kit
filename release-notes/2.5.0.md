- **Packaging an extra app built with Visual Studio's MSBuild**, such as a UWP Xbox Game Bar widget: a `companions` entry can set `"builder": "msbuild"` with the Visual Studio components it `"requires"`, and `"xaml": true` to package its compiled XAML. The companion keeps its XAML in a folder of its own: two apps in one package share its `ms-appx:///` namespace, and a clash fails the build.
- Third-party notices now list each companion's packages too, and leave out the .NET runtime's own Native AOT and trimming compilers. Run `npm run generate:notices` after the pin bump.
- A project that can't compile on Linux can set `<WinUIAppKitFormatWhitespaceOnly>true</WinUIAppKitFormatWhitespaceOnly>`. `npm run format` then fixes only its whitespace, and its Windows build enforces code style.
- **devkit 0.26.0:** `npm run icons` can also write an Xbox Game Bar widget's icons (`gameBarIcons` on the Windows target in `assets/brand/icons.json`), and fails when two outputs would write the same file. Committed icons don't change.

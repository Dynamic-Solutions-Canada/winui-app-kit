- Apps no longer ship Windows ML's native files (`DirectML.dll`, `onnxruntime.dll`, `Microsoft.Windows.AI.MachineLearning.dll`), which the Windows App Runtime already provides: about 18 MB off each package. No edits needed.
- The host window now runs your exit steps when Windows shuts down, restarts or signs out, or closes the app for an update; before, the process ended without them. Keep exit steps quick, since Windows waits only a few seconds. Set `HostWindow.ExitOnSessionEnd = false` to keep the old behaviour. If your app handled `WM_ENDSESSION` itself, delete that code.
- The host window no longer takes the foreground when the app starts, so starting at sign-in, or from an overlay such as Xbox Game Bar, leaves the user's current window in front.
- Exiting no longer waits five seconds. WinUI's shutdown never finished while a window that was never activated (a tray flyout, an on-screen popup) was open. Register every window your app creates itself and keeps open, such as an on-screen popup, with `HostWindow.CloseOnExit(window)`; the kit registers its settings windows and the tray flyout itself.
- Tray flyouts keep a gap from the screen edge, as Windows' own flyouts do.

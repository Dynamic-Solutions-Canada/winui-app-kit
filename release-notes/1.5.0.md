- New `StartupRegistration.RepointRunEntry()` for portable builds: call it once at startup and a copy the user moved, or replaced with a newer download in another folder, keeps starting with Windows instead of the old copy. It only rewrites an entry that already exists, so it never turns startup on and never undoes a choice the user made in Task Manager or Windows Settings. It does nothing when packaged.

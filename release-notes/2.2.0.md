- New: `scripts/devkit` runs devkit's icon generator and pre-commit check for your app without adding any Node dependencies to it. Add `"icons": "external/winui-app-kit/scripts/devkit icons"` and `"check:icons": "external/winui-app-kit/scripts/devkit icons --check"` (in `validate`), and `external/winui-app-kit/scripts/devkit precommit` with your own `--allow` and `--max-size` in `lefthook.yml`, where it replaces the signing-material, env-file and large-file jobs; keep your jobs for anything else, such as `.aws/`, `.windows-build/`, `*.snk`, `settings.json` and `protected-*.dat`, which it doesn't cover. It needs Node 22.12 or later, below 25; a CI job that runs it sets up Node first. See "Using it" in the README.
- New: every MSIX build also copies the package to `.artifacts/packages/<version>/` as `<package_name>-<version>-windows-<arch>.msix` (`-store.msixbundle` for a Store-identity build). The file in `package_output` keeps its current name. Name `package_name` in PascalCase; any other name builds with a warning.
- Changed: a build now removes older versions' packages from `package_output`, so it holds only the current version's pair for a manual upload. Earlier versions stay in `.artifacts/packages/`.
- Changed: the shared `.gitignore` block now ignores `/.worktrees/`. Paste the block from `build/shared.gitignore` again, or `check:gitignore` fails.
- Changed: `.editorconfig` puts HTML in the two-space section. Copy it again; a formatter that reads it may re-indent your HTML files.
- The Store workflow's gate now has Node 24 set up, so an app's `validate` can run `scripts/devkit`.

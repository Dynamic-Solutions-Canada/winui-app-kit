- New: `scripts/devkit` runs devkit's icon generator and pre-commit check without adding Node dependencies to your app: `scripts/devkit icons` (with `--check` in `validate`), and `scripts/devkit precommit` with your own `--allow` and `--max-size` in `lefthook.yml`. It replaces your signing-material, env-file and large-file hook jobs; keep the others (`.aws/`, `*.snk`, `settings.json` and so on). It needs Node 22.12 to 24. See "Using it" in the README.
- New: every MSIX build also copies the package to `.artifacts/packages/<version>/` as `<package_name>-<version>-windows-<arch>.msix` (`-store.msixbundle` for a Store-identity build). The file in `package_output` keeps its current name. Name `package_name` in PascalCase; any other name builds with a warning.
- Changed: a build now removes older versions' packages from `package_output`, so it holds only the current pair for a manual upload. Earlier versions stay in `.artifacts/packages/`.
- Changed: the shared `.gitignore` block now ignores `/.worktrees/`. Paste the block from `build/shared.gitignore` again, or `check:gitignore` fails.
- Changed: `.editorconfig` puts HTML in the two-space section. Copy it again; a formatter that reads it may re-indent your HTML files.
- The Store workflow's gate now sets up Node 24, so your `validate` can run `scripts/devkit`.

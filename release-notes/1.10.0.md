- The kit now generates your app's third-party notices. Point `generate:notices` and `check:notices` at `external/winui-app-kit/scripts/generate-notices.py` and delete your own copy. The defaults find your project, the notices file beside it and your product name, so most apps need no new settings; see "Third-party notices" in the README for the optional `notices` block.
- `check:notices` now also catches a broken About link to the notices: it fails when a GitHub link in your code names another path, and, if you set `notices.about_source`, when your `NoticesPath` constant doesn't match the notices file.
- Regenerate your notices once after switching: the header now says to run `npm run generate:notices` instead of naming your old script.

- The settings window now fits narrow widths. Below 860 wide the navigation pane shrinks to an icon rail, and the window can't be made smaller than 500 × 500 (on every monitor, at any scaling). Apps can pass `minWidthDip` and `minHeightDip` to `SetUpSettingsWindow` for another minimum, and `WindowChrome.SetMinimumSize` sets one on any window.
- The Store workflow's `pre_build` now stops when any command in it fails, including a command that fails before a later one succeeds.
- The credential reminder example now sets `STORE_SECRET_EXPIRES` as an organization variable, so a repository copy no longer hides the shared date.
- New `scripts/app-test/tour.ps1` screenshots every settings page in light, dark and high contrast in a test VM; see "Touring an installed app" in the README.

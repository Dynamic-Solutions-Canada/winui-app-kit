- The Store workflow can pass one build-time secret to your build: pass it as `BUILD_SECRET` and name the variable your build reads in `build_secret_env_name`. See "Publishing to the Microsoft Store" in the README for the caller shape.
- `hold_publication` on `submit_draft` holds a certified release until you publish it in Partner Center, and commits only if the hold and your price tier are kept.
- `inspect_draft` reports a submission's status, pricing and publishing mode without changing anything.
- The settings shell can now hold action items: a menu item with `SelectsOnInvoked="False"` raises `ActionInvoked` instead of opening a page.

- Nothing changes for an app that only bumps its pin, and nothing needs regenerating.
- **A text-free copy of the Store hero:** the kit now runs devkit v0.28.0, so a split hero can set `hero.textFreeFile` (for example `"text-free/00-hero-dark.png"`) in `store-assets/manifest.json`. `scripts/devkit hero` then also draws the hero's brand gradient and enlarged window with no icon, name or text, for a web page that sets its own headline above it. Keep the file out of `screenshots/`: check:screenshots and the Store upload use only the manifest's own entries, so it never reaches the listing. `check:hero` covers it.

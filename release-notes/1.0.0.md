- First tagged release. Pin this tag instead of a bare commit; later releases follow SemVer, so only a major version breaks your app.
- Covers everything apps on the kit already use: tray icon and menu, tray flyout, window chrome and placement, the JSON settings store, start with Windows with its status, theme switching, localization (`UiText`, `Localize`, `LocalizedMessage`) and app environment helpers.
- The kit is now MIT licensed (copyright Dynamic Solutions), so you can use it in any app.
- The README has a new "Gotchas" section: behaviour your app relies on, such as identity values that must never change, flyout lifetime and language resolution. Link to it from your app's docs instead of keeping your own copy.
- The repo now carries the family's canonical `.editorconfig`. Copy it into your app unchanged; with the analyzers on, expect missing-brace warnings in existing code until you add them.
- The kit now treats its own warnings as errors in Release builds, including your app's Release build of it. API and behaviour are unchanged from the previous commit.

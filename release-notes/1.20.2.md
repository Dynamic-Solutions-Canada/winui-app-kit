- The kit now builds with Windows App SDK 1.8.12 (1.8.260921001), the last 1.8 servicing release, up from 1.8.5. The releases in between are bug fixes only, with no security fixes listed, and include fixes for Windows 10 (the Windows App Runtime's Workloads library failing to load before Windows 11) and for XAML compiler errors being hidden under `dotnet build`.
- Raise your manifest's `Microsoft.WindowsAppRuntime.1.8` dependency to `MinVersion="8000.994.2142.0"` when you take this version, so a PC with an older runtime updates it before running your app.

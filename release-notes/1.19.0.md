- An app whose only window is visible (not resident) can now bring its running copy forward: `SingleInstance.RegisterWindow` after claiming, and `SingleInstance.BringRunningInstanceForward` from a second launch. See "Starting a resident app" in the README.
- `AboutInfo.Description` takes the About description from your own localization (for `.resw` apps), as an alternative to `DescriptionKey`.
- `l10n:Localize.Header` and `Placeholder` now work on `PasswordBox`, `NumberBox` and `AutoSuggestBox`, and a `Localize` property on a control that can't show it is logged as a warning instead of doing nothing.
- The kit's icon-and-label buttons now have screen-reader names. Buttons of your own built with `IconLabelStyle` need `l10n:Localize.Name` set to the label's key.

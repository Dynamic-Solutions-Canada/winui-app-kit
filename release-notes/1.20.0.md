- `UiText.Plural(key, count, ...)` picks `key.one` or `key.other` by each language's rule and fills `{{count}}`.
- A language's text can be split into area files, `<language>/<area>.json`, merged when the app reads it. `check:l10n` reads the same layout with `"catalog_layout": "folders"` and fails on a key defined in two areas or a plural missing a form.
- `UiText.DeviceLocale` and `UiText.Catalog(identity)` are new. Everything else about `UiText` is unchanged.
- The text core (`TextCatalogs.cs` and `SupportedLanguages.cs`) has no dependencies, so a companion process or test harness can link it and use `TextLookup` directly.
- `check:l10n` no longer mistakes values inside a `Format` call, such as a number format, for keys.

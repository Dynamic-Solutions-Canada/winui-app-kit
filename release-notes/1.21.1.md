- After an app update on Windows 10, the tray icon now still appears. Windows ties a tray icon's ID to the folder of the app that first registered it, and every update installs to a new folder, so Windows refused the icon after any update. The kit now adds it without that ID for the session when that happens. The icon and its clicks work as before, but the user's show-or-hide choice for it starts over after such an update.

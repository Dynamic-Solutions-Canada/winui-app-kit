- Breaking: the kit moves to Windows App SDK 2.6.5, because Windows App SDK 1.8 is out of support (its servicing ended in September 2026). In your app's `Package.appxmanifest`, under `<Dependencies>`, replace the `Microsoft.WindowsAppRuntime.1.8` `PackageDependency` with `<PackageDependency Name="Microsoft.WindowsAppRuntime.2" MinVersion="2.6.5.0" Publisher="CN=Microsoft Corporation, O=Microsoft Corporation, L=Redmond, S=Washington, C=US" />`. The Store installs the framework for users; install the 2.6.5 runtime on test PCs first. See "Windows App Runtime" in the README.
- Dependabot now offers Windows App SDK 2.x minor updates; only a 3.0 needs each manifest changed again.
- Log files are now named from the launch's start time in UTC rather than local time. Older local-time logs are cleaned up with the rest, so the folder still keeps four.
